# Poster Skills · 海报协作技能

| 技能 | 适用任务 | 安装包 |
|---|---|---|
| [海豹统筹 `$poop`](skills/poop/SKILL.md) | 接手整批海报、安排审稿、归档与交付 | [1.0.0](packages/poop_v001.zip) |
| [海报共创室 `$poso`](skills/poso/SKILL.md) | 梳理信息层级、探索风格与版式、制作可编辑单稿 | [1.1.0](packages/poso_v002.zip) |
| [开放首稿法 `$opdt`](skills/opdt/SKILL.md) | 共创构图、制作完整首稿、根据实稿反馈修改 | [1.7.0](packages/opdt_v010.zip) |

## 使用

下载所需安装包并解压，按所用 AI 工具的技能安装方式放入完整目录，保留 `SKILL.md` 与同级参考资料。使用整批统筹时，从项目已有的 brief 或工作单开始。

> $poop，接手这批海报，列出现在能推进的稿件，先给我看一张代表样稿。

风格参考的来源和许可见 [poso 来源清单](skills/poso/styles/sources/manifest.json)及[随包许可文件](skills/poso/licenses/)。
