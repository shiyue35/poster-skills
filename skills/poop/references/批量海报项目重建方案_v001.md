# 批量海报项目重建方案

v001 · 跨项目复用版。建新项目时，先定下资料放哪里、谁作决定、从哪份工程续改、最终交哪套文件。以后各批沿用这套约定。已有项目如果能清楚回答这些问题，可以直接进入批次制作。

制作步骤可查[批量海报 AI 共创手册](批量海报AI共创手册_v002.md)。本批信息沿用已有制作记录，需要新建时使用[批量海报制作工作单](批量海报制作工作单_v003.md)。

## 1. 建项时做四个决定

| 决定 | 在新项目里写清什么 |
|---|---|
| 做到哪里算交付 | 本项目有哪些用途和接收人，交成品图、适配尺寸、可编辑工程还是约定的整套。具体比例、格式、数量与期限以本批要求为准。 |
| 海报之间是什么关系 | 哪些稿共用视觉要求，哪些要用同一母版，哪些独立设计。可以用风格、活动主题或产品线作制作目录，只选一个最方便团队找稿的主分类。 |
| 谁维护资料、做决定 | 谁提供并纠正文案和主体，谁操作主工程，谁汇总意见、谁确认成品。写明 AI 能从哪个入口取得当前资料、可以自行推进哪些步骤。 |
| 如何认出“这一版” | 给每张可独立审阅的稿一个清楚的名字。约定工作版怎么升号、在哪里留审阅依据，以及哪些文件算实际交付。 |

把决定写在已有的项目说明或 brief 里。一批即可做完的小项目，直接用工作单第一节承担这个职责。以后有第二批时，再把两批都适用的规则抽到共用入口。

## 2. 目录跟着资料产生

从空目录开始时按实际内容建目录。已有项目沿用能接手的原位置，有现成的资产库、审稿平台或云端工程时留入口即可。

```text
项目/
├─ 项目说明.md                  共用事实、规格、负责人和各批入口
├─ 素材/
│  ├─ 公共/                     品牌标识等共用资产
│  └─ {对象}/                   指定原图、原始来稿和基础处理图
├─ 参考/                        视觉参考及用途
├─ 探索/{轮次}/                 候选说明、固定样稿、必要工程或入口
├─ 制作/
│  ├─ {制作批次名}_制作工作单.md 已有制作表能接手时继续用原表
│  └─ {风格或主题}/
│     ├─ 风格要求.md            已确认适用的共用要求
│     ├─ 工程/                  多张稿共用的母版及依赖
│     ├─ 公共组件/              跨稿复用时建立
│     └─ {稿件名}/              单稿记录、试稿、独立源文件与专用素材
└─ 交付/{日期-交付批次号}/      按当次实际交付范围保存文件
```

只为判断方向而做的样稿，包括完整可编辑海报，保存在对应探索轮次。用户只认可一个方向时，选择留在该轮。明确某张作为工作稿后，在稿件记录关联用户所见的固定版本，需要继续编辑时再建立工作副本。整批沿用的对象和范围根据另行或同次给出的授权确定。

统筹维护一批一张工作单。原始素材保留原名，共用文案只维护一次。主审只改一张时，决定随该稿记录。明确适用于多张的母版要求，先写在风格要求的对应小节，列出适用名单和例外。需要独立更新或交接时，再将该小节拆成与稿件目录同级的 `系列说明.md`。

## 3. 从第一张稿开始，留下足够的交接依据

| 什么时候 | 当时做什么 |
|---|---|
| 收到第一批资料 | 沿用原制作表，缺少可接手的记录时才建工作单，链接文案来源、指定素材和本批名单，标出能开工的稿。 |
| 第一次看稿 | 方向选择、构图选择、成品确认分别写清。现场核对记文件、画框与工作版。异步送审或需准确回看时留固定预览。 |
| 第一次从样稿延展 | 指定母版和适用范围，写清哪些文字、图像和结构能独立修改，选差异明显的一张验证适配。 |
| 首次交付或后续补交 | 在已有批次入口固定一次清单。若后来只补交一张，更新该用途指向的新文件，旧套装仍能按原清单取回。 |

**工程如何续改。** 为每份工程指定一处主编辑位置。小改先找指定底稿，已有匹配试稿就直接续改，需从成品新起时才完整复制。母版准备延展、已确认工程要继续改、依赖重大变化，或将替换唯一工程时，保存或核实对应版本及依赖。要承诺可以恢复编辑，就用独立副本重开、核对字体和图片、试改一处并导出。只有预览或只做过依赖核对时，如实注明已验证的范围。

**交付如何取件。** 确认对应到实际看过的版本。清单列对象、来源工作版、实交文件与规格、共同确认依据。用户另定成品编号时保留两种编号的对应关系。首次交付就能从已有入口取齐文件，以后按原入口继续登记。跨批取件或多个并行用途已难说清时，再拆出独立交付索引。

## 4. 用三个真实动作检查方案是否够用

请一位接手者从项目入口找出指定稿的正确可编辑底稿，区分用户确认的旧版与正在修改的新版，在单张补交后分别取回当时确认的整套与下次要用的组合。哪一步需要猜，就补那一步缺少的命名、链接或决定。三件事都能完成时，继续制作即可。
