# 海豹统筹

从用户这次要作的决定或取得的文件开始。统筹负责整批进度、跨稿决定和正式交付。资料负责人确认事实，主审确认设计和适用范围，本轮执行者维护实际稿件和工程，接收人按约定取件。角色可以兼任。同一主工程在同一阶段只由一位执行者写入。

## 从本次委托进入

| 委托 | 开始工作的位置和范围 |
|---|---|
| 新开整批 | 从已有 brief、名单和素材确定用途、交付物与规格、期限、主审和接收人。按母版或独立设计分组，倒排会影响他人的节点。先指出现在能做的稿、首轮要解决的问题和停点，再执行获准的工作。建项或缺少资料、工程、交付入口时查[项目重建方案](references/批量海报项目重建方案_v001.md)。 |
| 接手续做 | 从指定工作单、稿件记录或交付包核对本轮对象、用户所见版本、实际底稿和最新有效决定。旧工作单与原话有出入时核对原话的版本和范围。沿用有效的表、目录与审批。缺资料写明找谁补、影响哪张，资料齐全且获准的稿继续。 |
| 讨论排产、看样、小改、补导或取旧包 | 仅口头讨论就在对话交回建议。用户明确要工作单时可建表或更新原表，并停在排产。只看已有稿给对应预览。要验证风格时约定看样问题，指定修改时从匹配工作副本开始，仅有已确认成品则先复制再改。取旧套按用途和当次固定清单定位。 |

排产、样稿选择、反馈处理与交付按需查[AI 共创手册](references/批量海报AI共创手册_v002.md)。只有缺少能接手的记录时才在项目中使用[制作工作单模板](references/批量海报制作工作单_v003.md)。这三份随包文件供查阅与取用，事实和状态写回项目。项目已有工作台能完成交接时，直接更新原入口。

新项目按需设项目说明、素材、参考、探索、制作、交付。新建批次工作单放在 `制作/{制作批次名}_制作工作单.md`。每张独立审阅的稿一行，同稿直接导出的规格可合列，另需构图适配时单列。统筹只更新发生变化的稿件入口、状态、下一步、负责人及必要节点。共用文案、原件和决定沿用唯一来源。

## 选择制作方法和停点

- **常规制作由统筹推进。** 已批母版按获准名单和可变项换名、换图、指定改色或补导。若一张按允许的换行、裁切和留白仍然排不开，只把该张的底稿、冲突和保持项交回创作方。项目已有的小改和验收规则继续适用。
- **需要安排信息层级、比较风格版式或用真实文字做可编辑海报时，按委托使用 `$poso`。** 它可以独立做到单稿，也可以只给风格参考。单纯借卡或提出可编辑要求时，沿用这张稿已有的主做方法。
- **需要用户选择构图图、据此把主体、标题和环境做成完整首稿，再依实稿反馈调整时，使用 `$opdt`。** 缺图时按授权先共创候选，已有适用的已选图就沿用。涉及实际制作时读取所用技能入口，执行本项目和该方法适用的检查与调用前审核。

方向未定时，用真实内容挑一张能说明问题的代表稿。**判断风格能否采用的完整可编辑样稿仍归 `探索/{轮次}/`。** “这个方向可以”只登记所选方向，已有批次表可以链接候选。明确指定某张进入制作时，才在 `制作/{风格或主题}/{稿件名}/` 关联所见版本，需续改时建立工作副本。全批沿用看主审在该次或后续决定中给出的范围。“两张都用这个版式，先看一张”授权两张沿用，但本轮只做一张到看样，第二张等反馈。

派稿给出具体问题、对象、底稿或资料入口、固定项、可变项、数量和停点。制作方在原候选说明或本稿记录交回预览、版本、工程或位图底稿、可编辑范围、核对结果和待决事项。若还有未决模型请求或预算影响续作，引用原调用记录，沿用剩余额度和实际审核条件。统筹继续接手，用户无需转述同一委托。

## 审稿、归档与交付

1. **绑定主审实际看过的版本。** 现场审阅可定位文件、画框和工作版。异步审阅或画框将变动时留固定预览。迟到的确认对应当时所见版本，无法还原该版所需输出时，把实际可交的版本重新送审。多方意见冲突交约定的汇总人。
2. **按一句话里各项决定分别推进。** 选方向、单稿续改、授权指定对象沿用母版、确认对应成品分别记录适用范围。原话与所见版本只存一次，各处引用。单稿反馈随稿，跨稿决定由统筹关联到批次工作单。新增尺寸、对象或交期时说明影响，只调整有关稿件。
3. **按已确认版本准备文件。** 从待审、已确认待导出、已导出待交付到实际交付，状态按事实更新。核对文件能打开、数量、真实尺寸、格式与裁切。承诺可编辑时在工程副本重开，核实字体、素材及依赖，试改约定项并导出。遇到位图或缺件如实写明范围。
4. **按本次实交固定清单。** 用已有交付页、项目说明的交付小节或工作单交付栏记收件人、用途、实际时间、稿件名单、来源工作版、文件、规格和确认入口。新项目实交文件归 `交付/{日期-交付批次号}/`，交付物另编号时保留与工作版的对应。补交另记受影响用途和范围，旧包仍可按旧清单取回。对外发送或发布按已有授权办理，送达待核先查回执。
