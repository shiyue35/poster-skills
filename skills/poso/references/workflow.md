# 任务理解、参考范围与方案共创

## 形成够用的任务约定

从已有对话与本轮项目资料提取以下内容；已有答案不再询问，无需强制填表或新建 brief。

| 决策 | 必须能回答的问题 |
|---|---|
| 传播目标 | 谁在什么场景看到它，希望记住什么、采取什么行动？ |
| 事实与素材 | 哪些文字必须逐字正确？哪些主体、标识或照片已指定？哪些事实尚缺？ |
| 信息层级 | 第一眼是什么，第二眼如何补充，行动信息在哪里？哪些姓名／日期／身份必须同组？ |
| 约束与自由 | 什么保持，什么可调整，什么明确不采用？ |
| 使用与交付 | 在哪里展示，尺寸、格式、编辑性、系列一致性要求是什么？ |
| 任务预算 | 本轮范围、已有额度与剩余额度是什么？ |

事实不清楚时，不捏造活动时间、资格、价格、背书、文案或品牌关系。讨论阶段可用明确标注的占位符；进入实际制作前，处理会影响成稿的缺口。用户已授权自行选择的普通设计判断由制作者完成。

信息层级要可观察：例如“标题先读到；主体负责辨认与情绪；姓名与日期形成第二组；报名入口最后承接行动”。让字号、位置、对比、间距、遮挡与留白共同实现这条阅读路径。设计师的意图不能代替缩略图和实际尺寸下的阅读核对。

## 给参考分配角色和采用范围

实际查看将被采用的图片，区分身份／主体参考、构图参考、风格参考、配色参考、可直接复用的原件。一张图可承担多个角色；无权或无能力查看时明确限制，不能假称已看过。

简短说明足够，例如：“采用奶油纸感与胶带；保持原宠物外貌和已确认文案；参考图中的英文仅供气氛；主体位置和标题形状仍可探索。”

- **采用项**：本稿具体借鉴的布局关系、材质、色彩或视觉手法。
- **保持项**：用户已确认或项目规定必须保留的内容与关系。
- **仅供参考项**：不自动复制的源图文字、品牌、脸、字体、日期、比例等。
- **开放项**：允许探索的构图、环境、装饰、字体类别或风格变化。

选参考并不自动锁定全图；构图草图中的占位文字、临时色板和未讨论细节不自动成为硬要求。只在有实质歧义时确认范围，不能把每张参考变成新的审批关卡。选择方向后的制作授权按原任务语义判断，不重复索取已有授权。

## 风格与构图共同探索

先提出连接内容与视觉的概念，例如“用训练笔记组织参赛信息”，再判断手帐风、信息分组与主体位置如何一起表达它。可以先从已有风格进入，也可以先解决困难的信息组织；顺序服务任务，不规定“永远先风格”或“永远先构图”。

筛选候选时先排除违背真实主体、文案密度、信息层级及输出条件的方案，再比较情绪、品牌和表达适配度。给出一个推荐方向，必要时补充少量真正不同的备选；只换颜色的方案应称为同方向变体。解释推荐如何服务目标，不能只报风格名。

用户希望共同选择时，可用已授权且可查看的案例、简图、文字示意、排版草图或模型草图帮助判断；模型草图也计入任务预算。没有必要时不先制作中间图。用户让你决定时，说明关键假设并继续，不强制等选稿。

方案确定到足以制作即可：锁定本稿目标、必要文字和关系、主体保持范围、主要风格语言；无需提前锁死每个像素。若用户只要求讨论，到此提供可审阅方案，不进入生图与文件保存。

## 探索样稿与单稿工作版

按这次看稿要做的决定归放文件。只是判断一个风格值不值得采用，候选图、完整预览及必要工程或其入口都留在本轮探索记录。采用“探索／制作”结构的新项目放在 `探索/{轮次}/`。已有项目沿用相应探索位置，即使样稿已排完真实人物和全文，也不为它建立制作目录、改风格要求或登记母版。若已有批次工作单，统筹可在原行链接候选并注明待审。

“想看试稿”沿用当前委托的目的。探索中说“方向可以，先到这里”，把选择留在该轮记录即可。用户明确指定某张为工作稿，或说“就从这个版本继续做这张”，才在该稿制作位置关联所见的固定版本。选中的样稿已够用就直接引用，需编辑时从它建立工作副本，保留探索原件。一张获准制作并不授权其他对象沿用。

在上述新项目结构中，工作版归 `制作/{风格或主题}/{稿件名}/`，预览放 `试稿/`，可编辑工程及依赖放 `源文件/`，本稿需复用的组件放 `专用素材/`，按实际内容建立。原始素材与参考从项目已有位置读取。受托设计跨稿母版或公共组件时才按项目约定更新相应共用工程。

## 现稿、组件与系列

- 现稿修改：以用户指定的基准版本为起点，区分恢复原要求与新增目标；保留未要求变化的层级、主体及有效结论。
- 独立组件：明确组件用途、透明背景／边缘／衔接与尺寸条件；组件结果不冒充完整海报。
- 系列适配由统筹按已批准的对象和可变项推进。遇到允许的换行或留白仍解决不了的遮挡，只交回问题稿、指定母版、固定项和冲突。单稿解法要推广到其他对象时，以相应授权为准。
