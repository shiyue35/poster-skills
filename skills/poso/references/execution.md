# 制作、任务级预算与反馈回退

## 选择能完成交付的路径

依据精确文字、主体保持、可编辑性和工具能力，选择完整生图、生成视觉素材后真实排版，或混合路径。用户指定的方法优先；确有能力限制时解释其对结果的影响及可选路径，未经依据不能把用户要的可编辑工程换成位图。

生图前按当前环境读取适用的生图工具／技能要求；poso 不内置虚构 API、模型或独占后端，也不自动安装软件。输入说明应包括：传播目标与阅读顺序、准确文案、参考角色与采用范围、主体保持项、开放项、画幅及交付条件。把“高级”“有设计感”等词转成可执行的字号关系、材料、边缘、色彩、光线、透视和留白描述；清除外部案例中的原品牌、日期、人物设定与无关限制。

目标尺寸、工具实际生成尺寸和后续导出尺寸分别说明。只有工具支持并实际生成，才能称为原生尺寸；裁切、扩边或放大不得冒称原生输出。不把某一工具的尺寸限制推广到全部任务，不默认所有海报为 9:16。

字体与字形按实际路径说明：真实字体层记录所用字体及已查到的许可条件；AI 绘制的字无法据画面识别为某款字体，也不能保证绝无相似字形风险。精确长文案、必须更改的文字或明确字体要求，用合适的真实文字排版方式解决；位图文字只作位图交付。

## 任务级调用预算

预算覆盖当前已授权任务的全部对象、方向和产物。它在首次实际模型调用前建立，沿任务延续；讨论与普通资料读取不消耗生图调用，但同样受用户时间和费用约束。用户新增独立任务或明确批准扩大范围时，先说明新额度与原消耗的关系。

同一委托中更换方法或执行者，接续原记录中的已用额度、剩余额度及未决请求。进入开放首稿法时，原任务总上限与其对本次请求、对象和方向的限制同时适用，实际模型调用执行其独立审核要求。查阅风格卡本身不消耗模型额度。

1. 优先执行用户指定的调用、张数、费用、时间上限，明确“调用”是否允许一次返回多张；不要把张数与调用数互换。
2. 用户没有给数字时，根据本轮目标提出**有限**方案：要交付什么、哪些调用用于探索／制作／必要修正、预计调用数及本轮最高调用数、可观察费用或未知项、停点。不得用一个固定数字覆盖全部任务。
3. 简短告知即可在已有授权内执行。仅当用户要求先批预算，或新计划显著扩大数量、费用、时长／方向范围时，再等待对应决定。

示例是推导方式而非默认额度：已经选好参考的一张海报，可计划一次制作并按实际难点预留有限修正；六张不同对象的系列则需按实际工具的批量能力和共用修改风险重新估算。不要机械套用两次调用，也不要无论复杂度都预留相同重试次数。

运行时保留够用的一行台账或沿用工具日志：用途、调用状态、返回张数、实际可见费用、累计调用／剩余额度。模型生成的草图、正式稿、失败重试、换方向及修正都占额度；已经发出的失败请求计入尝试，能确认未发出／未计费时再明确更正。挂起、超时和费用未知的请求不能按免费处理或盲目补发。

版式示意、人工排版、导出和裁切等非模型操作不冒充生图调用，但仍受交付范围、时间、费用及其他工具权限限制。一个工具调用返回多张时同时报告调用数与图数。

达到以下任一条件时停止继续花费，交付已有可用结果、说明缺口并给出最小下一步；需要用户决定的扩展留给用户：

- 达到任务计划上限或用户的任一有效上限。
- 继续工作需要显著增加成本、时间、方向或产物范围。
- 相同策略重复失败且没有新的诊断、输入或方法。
- 工具不能完成要求，或修正必须牺牲另一项已确认要求。

额度未用完不意味着应该继续调用。每次修正必须有明确问题、影响范围和改变策略；不存在另起版本、换工具或改叫“验证”就重置的隐藏额度。不得自动无限重试。

## 反馈回到原因所在

| 反馈原因 | 返回位置 | 下一步 |
|---|---|---|
| 目标、事实、逐字文案理解有误 | 任务理解 | 更正对应依据，保留有效决定；不以换风格掩盖内容错误 |
| 内容正确，但层级、阅读路径或创意不成立 | 方案探索 | 重组信息与概念，必要时连同构图和风格调整 |
| 方案合理，主体、字形、局部位置或质感执行漂移 | 制作 | 对准失真项修正，按实际工具选择编辑、局部重作或排版 |
| 尺寸、格式、导出或裁切问题 | 交付处理 | 能通过正确导出解决时无需重新生图 |
| 参考不适用或风格和约束冲突 | 参考／候选选择 | 修订采用范围或换候选，不把事实、身份要求让位给风格 |

每轮先判断是在恢复已确认目标，还是用户改变了目标。后一种更新相应约定与预算范围，前一种记录偏差及修正，不让执行错误反向改写 brief。不要因局部意见就丢弃整张或重审全部历史。

## 核对与收尾

实际看结果，检查本轮涉及的准确文字、信息层级、主体保持、参考采用及输出条件。首次完整制作看整体，局部修改看修改及其影响，单纯导出只查尺寸、格式、裁切与完整性。直接使用 poso 时制作者自行核对，按用户、项目或实际制作方法的要求执行独立审核。规定的模型调用前审核无法完成时，停在该次调用之前。其他情形按具体风险决定是否需要额外审核。

单独委托按停点直接交给用户。讨论交文字，审稿给可定位的预览，要求可编辑时交对应的工程入口，说明实际可编辑范围和必要依赖。只有位图时说明底图和修改限制。单张可在此结束，无需建立批次工作单。

批量协作或用户随后要求铺开、正式归档时，制作方交回同一条候选说明或本稿记录。关联固定预览、实际版本、工程或底图、核对结果和待决事项。用户已作决定时，引用原话与所见版本，写清适用的稿件、阶段和用途。会影响接手的调用与余额引用原记录。保留原图、旧交付和工程依赖。

统筹在原工作单引用该入口，按授权安排下一步。已批准母版沿用，只推进许可范围内的对象并遵守“先看一张”等停点。明确成品确认后，统筹按实际进展区分已确认待导出、已导出待交付和已实际交付，并办理正式归档。对外发布按对应授权执行。
