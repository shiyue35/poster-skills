# 独立审核与受控执行协议

技能版本 1.7.0。行为要求引用[通用方法](method.md)，本页规定审核绑定与可选程序接口，避免另存一套项目规则。

## 1. 准备与独立审核

仅实际图像模型生成／编辑触发独立审核。纯讨论、查看、选稿、非模型绘图和普通导出不触发；制图仍须有对应授权与适用检查。审核不可用时停止相应模型调用；其他已获准工作按[方法第5节](method.md#5-工具失败与轻量收尾)判断是否可继续。

制作代理提供当前任务类型、对象／方向／版本、用户请求与授权原始出处、适用 skill／brief／风格条款、实际完整提示词和参数、图片路径／顺序／用途。局部任务附母稿或设计依据、保持项、修错或已确认变更目标，以及仍有效的原始证据。

启动新上下文的只读审核子代理，不继承制作代理的分析或通过结论。审核者自行读取原始资料与实际输入，不改需求、不生图、不代选构图、不替用户批准变更；无法独立启动不能伪造记录或用主代理自审替代。

## 2. 按任务核对

| 程序阶段值 | 任务范围 | 审核 |
|---|---|---|
| `composition` | 构图共创 | 方法第3节共创5项，允许没有现成构图图／已选方案或参考图片。 |
| `generate` | 完整首稿或独立重做 | 完整制作10项，须传入已选构图图，整图统筹。 |
| `edit` | 基于现稿的局部修错或已确认变更 | 10项适用结论，引用未变化的原始依据，只复核本次修改及影响，输出局部任务要求的结果。 |
| `component` | 明确授权的独立组件 | 10项适用结论，核对设计依据／独立用途、保持项和组件范围，不要求额外生成整张海报。 |
| `extend` | 明确母版的系列延展 | 10项适用结论，核对母版固定项与新对象输入。 |

不得将海报或组件任务标为共创来绕过检查。审核区分修复既定目标和改变目标；前者在既有授权内，后者须有用户明确决定。尺寸、预算、单稿范围等按方法核对，未知和冲突不填通过。

可给审核者以下任务：

> 独立读取所附原始依据和实际图像请求，按当前任务的5项或10项条件核对范围、授权、文案／素材、构图、规格、预算及输出。局部任务引用有效原始证据，检查变动与影响，不以制作代理的结论为前提。给逐项证据和通过／阻断／需用户决定的结论，不补造授权或豁免。【附原始入口、任务类型、保持／修改项、完整参数和图片清单】

## 3. 结论与输入绑定

记录真实审核者及时间，绑定当前用户请求、任务类型、对象／方向／版本、工具、最终提示词、图片顺序与内容、原始来源版本／摘要。共创检查编号1—5，其他制作编号1—10；沿用项仍给原始证据，不把审核通过当作用户选图、用户确认或制作授权。

- 通过：本轮适用条件齐全，实际请求一致，有对应授权，无未解决问题。
- 阻断：当前阶段缺项、未经授权的替代、对象／阶段错配、输入或来源变化、审核／校验故障。修复后只复核受影响部分。
- 需用户决定：需求冲突或适用范围不清；保留原要求，停止受影响调用，已明确的同一决定不重复询问。

调用前再次核对实际输入。新模型调用需要本次绑定的审核依据；新提示词、图片、来源、任务或预算策略变化需重新审核。复核可引用未变化的原始证据，不能仅继承通过结论。共创通过不等于完整制作通过。

## 4. 可选程序集成与验证

[校验模块](../scripts/preflight_gate.py)只服务可信宿主，不自动安装 hook、连接图像服务或拦截内置工具。签名／摘要证明输入一致性，不证明自然语言授权真实、用户已选构图、图像质量或实际出图尺寸达标。

宿主在制作代理权限之外保存 Policy、审核者注册、密钥、提供方回调和共享 BudgetLedger，并从真实用户决定与独立审核编译策略；制作代理不能自签、伪造审核身份或更换计次标识。未知阶段、缺策略字段或校验故障均拒绝。

Policy 除对象、风格、版本、工具、原生目标、必需文字及参考／来源外，还须包含：
- `request_id`：本次用户明确制作／改稿请求；模型自增版本或切换阶段不换ID。
- `direction`：用户已授权的方向；不能拆方向增加额度。
- `is_revision`：本次是否修改已有画面，按实际目标判断，含参考图本身不代表修正；`edit` 必须为真。
- `max_calls`／`max_revisions`：按方法默认或用户明确上限编译，不由制作代理放宽。

宿主将本次逐项结论编译为包含 id、status、evidence 的审核条目；真正通过项（含方法允许的有据不适用／沿用项）使用 status 为 pass，evidence 保留理由及原始出处，不把中文状态或不适用标签直接作为程序通过凭据。

请求元数据需与 Policy 一致，参考清单按路径、顺序和字节绑定；共创可省略空图片参数，其他制作须有参考图片，其中的已选构图用途由审核与宿主核实。实际后端发送冻结后的图片字节，不重新用可变路径取图。

审核凭据带唯一审核ID；同一凭据只能支持一次实际发送，重复签发执行许可也不能重复发送。提供方存在、签名／快照／来源检查成功后，在同一个共享账本中原子校验并记账：按任务、用户请求、对象和方向累计，阶段与版本不重置；失败或超时发生在发送后不退款。发送前拒绝和未连接提供方不记调用。这里计数的是向已配置 sender 发起的调用尝试，不推断其内部 HTTP 次数或服务商计费。模块不统计金额或跨宿主全局支出，费用上限仍需宿主另行控制。

所有 Executor 必须显式使用同一个宿主账本；新 Executor 不重置已用次数。当前账本为进程内状态，宿主重启不能被解释为用户授予新预算，需由宿主恢复状态。参考实现不等于独立权限服务或持久化服务。

改动模块或协议后运行（仅本地临时夹具和模拟回调，无真实审核／图像服务）：

```powershell
python -B -X utf8 "scripts/test_preflight_gate.py"
```

随包测试覆盖阶段、输入绑定、单次凭据、预算与失败路径，同时检查文件链接和版本。实际部署还须验证凭据／策略隔离、唯一发送入口与真实接入的拒绝路径；本地测试不能证明内置工具已被拦截。报告必须分别说明独立审核、模块测试和真实工具覆盖情况，不以演示凭据放行实际生图。
